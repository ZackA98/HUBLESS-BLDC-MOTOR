# Test Log

> One entry per test run, copied from this template. IDs match `docs/testing-plan.md`. **Record measured values only — never planned or expected values.** Failed tests stay in the log; that's what it's for.

## Template

```
### [TEST-ID] — [Test name] — [YYYY-MM-DD]
- Build/config: (which assembly, ESC settings, battery SoC)
- Setup: (bench/vehicle, instruments used)
- Procedure deviations: (anything done differently from the plan)
- Measurements: (raw numbers, units)
- Result: PASS / FAIL / PARTIAL
- Notes/issues: (link issues opened)
```
